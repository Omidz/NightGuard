# NightGuard 1 (PowerShell)

This is the original PowerShell version of NightGuard, kept for reference. It is no longer developed.

NightGuard 2 (the C# app, service and MSI installer in `src/` and `installer/`) replaces it. Installing NightGuard 2 on a PC that has this version carries everything over (settings, trusted-person code, unlock request, streak, journal) and removes the old scheduled tasks and scripts.
